# 🧥 Blur Vintage

**Blur Vintage** is a full-stack e-commerce web application built for selling vintage clothing.  
The platform provides a smooth shopping experience with server-side rendered pages, user authentication, and a well-structured backend following the **MVC (Model–View–Controller) architecture**.

---

## 🚀 Features

- User authentication (Sign up / Login)
- Browse vintage clothing products
- Product listing with detailed views
- Server-side rendered dynamic pages using EJS
- Clean and maintainable MVC-based project structure
- Secure backend using Express.js and MongoDB
- Responsive UI built with HTML and CSS

---

## 🛠️ Tech Stack

### Frontend
- EJS (Embedded JavaScript Templates)
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose ODM)

### Architecture
- MVC (Model–View–Controller)

## 📁 Project Structure


## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/sreeshanthh007/blur-vintage.git
cd blur-vintage
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Environment Variables
Create a `.env` file in the root directory and add:

```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
```

### 4️⃣ Run the application
```bash
npm start
```

For development mode:
```bash
npm run dev
```
