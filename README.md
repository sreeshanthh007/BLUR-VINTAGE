# 🧥 Blur Vintage

**Blur Vintage** is a full-stack e-commerce web application built for selling vintage clothing.  
The platform provides a smooth shopping experience with server-side rendered pages, user authentication, and a well-structured backend following the **MVC architecture**.

---

## 🚀 Features

- User authentication (Sign up / Login)
- Browse vintage clothing products
- Product listing with details
- Server-side rendered dynamic views using EJS
- Clean MVC-based project structure
- Secure backend with Express & MongoDB
- Responsive UI using HTML & CSS

---

## 🛠️ Tech Stack

### Frontend
- EJS (Embedded JavaScript Templates)
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose ODM)

### Architecture
- MVC (Model–View–Controller)
